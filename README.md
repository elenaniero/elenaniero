## Projects
- **Iterative prisoner's dilemma:**
 Simulation of the Iterative Prisoner's dilemma in several settings: two players with different strategies, then multiple players in a round-robin scheme, with "genetic mutations" and players adapting their strategies. The aim was to build solid Python programming skills.

- **[Data Re-uploading for a Universal Quantum Classifier](https://github.com/melissanespeque/data-reuploading-classifier/tree/main):**
In this project, we used Python and Qiskit to reproduce and analyze the quantum classification framework proposed by Pérez-Salinas et al. (2020) in “Data Re-uploading for a Universal Quantum Classifier.” The paper introduces the concept of data re-uploading, a technique that embeds classical input data multiple times throughout a quantum circuit, enabling a single qubit to act as a universal classifier.

-**[Analysis of Covid 19 papers](https://github.com/polinagridiaeva/Analysis_of_Covid_19_papers):**
Analysis of COVID-19 research papers using distributed computing with Apache Spark. The project implements tasks such as word counting, title embedding, and finding similar papers through cosine similarity, all run on virtual machines and    resources provided by CloudVeneto. The aim of the project was to gain confidence in working with a computing cluster, to benchmark performances, and to learn the basics of NLP.

-**[Modelling Anthropogenic CO2 Accumulation](https://github.com/PhyAMR/ASPA_Project/):**
This project investigates whether the long-term increase in atmospheric CO2 is better described by a constant linear trend or an accelerating quadratic one. It applies Bayesian analysis, performs model comparison, and produces predictive forecasts.
