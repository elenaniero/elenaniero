## Projects
- **Iterative prisoner's dilemma:**
  Simulation of the Iterative Prisoner's dilemma in many of it's aspects: between 2 players with different strategies, extending to multi-players in a round-robin scheme, with "genetic mutations" and letting the player's change their strategies. The aim of the project was to build solid Python programming skills.
- **[Data Re-uploading for a Universal Quantum Classifier](https://github.com/melissanespeque/data-reuploading-classifier/tree/main):**
  A reproduction study of the paper ["Data Re-uploading for a Universal Quantum Classifier"](https://quantum-journal.org/papers/q-2020-02-06-226/) by Pérez-Salinas et al. (2020), implemented in Python and Qiskit for the Laboratory of           Computational Physics Project.
-**[Analysis of Covid 19 papers](https://github.com/polinagridiaeva/Analysis_of_Covid_19_papers):**
  Analysis of COVID-19 research papers using distributed computing with Apache Spark. The project implements tasks such as word counting, title embedding, and finding similar papers through cosine similarity, all run on virtual machines and    resources from the CloudVeneto server. The aim of the project was to gain confidence in working with a computing cluster, to benchmark performance, and to learn some basics of NLP.

-**[Modelling Anthropogenic CO2 Accumulation](https://github.com/PhyAMR/ASPA_Project/):**
This report investigates whether the long-term increase in athmospheric CO2 is best described by a constant linear increase or an accelerating quadratic trend. The project applies the statistical methods on Bayesian analysis studied in the Advanced Statistics for Physical Analysis course.
